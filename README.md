# 🏎️ Porsche Sales Dashboard

## Contexto

Este projeto foi desenvolvido como desafio prático do mini curso **"Aceleração: AI Reports com Excel, GPT Agents e Claude Code da DIO"**. O objetivo foi construir, com apoio de agentes de IA, uma dashboard analítica interativa em HTML/JS puro (sem backend) para explorar dados de vendas da Porsche — modelos, cidades, métodos de pagamento, status de entrega e ticket médio — em um único arquivo autocontido, pronto para abrir em qualquer navegador.

## Funcionalidades

- KPIs de vendas, modelo/cidade/ano líder, ticket médio, mediana e taxa de cancelamento
- Filtros por modelo, ano, cidade, forma de pagamento, status de entrega e período
- Gráficos: top modelos, vendas por ano, cidades, métodos de pagamento, ranking de vendedores e status de entrega
- Exportação do recorte filtrado em CSV
- Identidade visual da Porsche (brasão e wordmark) aplicada ao layout

## Conclusão

O desafio permitiu aplicar, na prática, o uso de agentes de IA como copiloto em todo o ciclo de um projeto de dados: da análise crítica de um dashboard já existente (identificação de bugs, dados subutilizados e oportunidades de UX) até a implementação incremental de melhorias — desde correções críticas (moeda, uso do campo de status de entrega) até refinamentos de acessibilidade e usabilidade. O resultado reforça como agentes de IA podem acelerar tanto o diagnóstico quanto a entrega de soluções analíticas, mantendo o controle e a validação técnica do desenvolvedor em cada etapa.
